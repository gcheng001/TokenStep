# Interstellar / Event Horizon artwork

These two original background plates were generated for TokenStep 0.2.7 from the user-approved “Natural Horizon Close-up” design direction.

- `InterstellarEventHorizonHero.png`: normal cinematic exposure for the popover, Today dashboard, Token Island, and share cards.
- `InterstellarEventHorizonQuiet.png`: lower-luminance plate for settings, history, privacy, the update window, and Reduce Motion states.

The production UI adds its own translucent panels, progress rings, accessibility veil, and lightweight accretion-flow animation. No movie artwork, logos, characters, spacecraft, or third-party watermark is bundled.
