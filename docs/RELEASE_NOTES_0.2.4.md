# TokenStep 0.2.4 — 奥德赛主题皮肤包

0.2.4 将 TokenStep 从单一配色升级为可切换的主题皮肤包，并新增完整的奥德赛电影化视觉系统。

## 新增

- 新增“经典”和“奥德赛”两套主题皮肤包；经典保留青绿、海蓝、紫藤、琥珀和石墨五种原版配色。
- 奥德赛包含导演剪辑、爱琴海冷雾、特洛伊火海和灰烬神像四个视觉篇章。
- 新增奥德赛弓箭阶梯 Logo、电影背景板、头盔、木马、神像、弓箭、长矛、海雾、火星和希腊回纹等原创主题元素。
- 菜单栏浮层、Today、历史、隐私、设置、更新窗口、分享卡与 Token Island 全面接入主题皮肤包。

## 浮层改版

- 奥德赛浮层改为“今日用量 / Agent 用量 / 订阅额度”三段式电影构图。
- Agent 消耗榜改为底部横向信息带，不再形成第五列或把浮层横向撑宽。
- 额度区支持多来源紧凑显示；排行榜关闭后浮层会自动收短。
- 经典主题继续保留原来的横向数据布局。

## 主题与迁移

- 可随时在设置里切回经典主题，并分别记住上次使用的经典配色和奥德赛篇章。
- 0.2.3 的 Voyage 设置会自动迁移为奥德赛导演剪辑，不影响其他设置。
- 奥德赛用量色采用骨金、冷金、余烬橙或石灰金；绿色仅用于同步成功等状态反馈。

## 隐私与兼容性

- 统计口径和本地优先原则保持不变；电影背景板不包含用户数据、电影海报、演员肖像或片方素材。
- 支持 macOS 14 及以上的 Apple Silicon Mac。
