# TokenStep 0.2.5 — 动态特洛伊火焰、模型用量与更新提醒

0.2.5 在 0.2.4 奥德赛主题皮肤包之上，新增可暂停的特洛伊火焰动效、菜单栏浮层模型用量，以及覆盖整个 App 的更新检查与提醒。

## 奥德赛动态火焰

- 特洛伊火海篇章的原有火焰纹理会产生局部向上扰动和亮度闪烁，并辅以烟雾、火星和余烬。
- 动效只在真实菜单栏浮层可见时运行；关闭、遮挡、截图或离开特洛伊篇章后会暂停并移除动态渲染层。
- 截图与分享继续使用确定性的静态背景，不会因动画帧不同而改变内容。
- 经典主题、爱琴海冷雾、灰烬神像及导演剪辑的原有表现保持不变。

## 浮层今日模型用量

- 在 Agent 来源下方新增“今日模型”区，直接查看各模型当天 Token 与占比。
- 1–3 个模型逐项展示；4 个及以上自动整理为 Top 3 +「其他」。
- 「其他」包含所有折叠模型的真实 Token；占比仍以今日总 Token 为分母。
- 长模型名、空数据、等待明细、超大数值和明细合计不一致状态均有对应显示。
- 删除圆环和 Agent 区域中两条重复解释文字，并收紧奥德赛顶部卡片高度。

## 全局更新检查与提醒

- 主窗口与菜单栏浮层都增加检查更新按钮，并共用 idle、checking、up-to-date、available、failed 五种状态。
- 自动检查覆盖启动约 30 秒、低频 6 小时定时和回到前台补查；所有入口共享并发门和节流规则。
- 手动检查即使关闭自动检查仍可使用，并可重新查看此前跳过的版本。
- 发现新版后，菜单栏出现下载标记，浮层及主窗口页面显示更新提示卡。
- 修复检查完成后图标仍持续旋转的问题。

## 安全、隐私与兼容性

- 更新仍通过 GitHub Releases 的已签名、公证 DMG，并继续由用户确认后安装，不做静默强制更新。
- 没有新增更新服务器、遥测、账号或系统通知权限。
- Token、金额、额度、排行榜及数据采集口径保持不变。
- 支持 macOS 14 及以上的 Apple Silicon Mac。
